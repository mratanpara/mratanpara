**My work:** Laravel REST APIs, Passport authentication, Google Sign-In with Socialite, unique URL aliases, multi-domain routing, collection permissions and Filament/Livewire dashboard development.

**Tech:** PHP · Laravel · MySQL · Passport · OAuth2 · Socialite · Filament · Livewire · Flutter · GetX · Swagger

**Tech:** PHP · Laravel · MySQL · Flutter · Passport · OAuth2 · Eloquent · FCM · Swagger

**Tech:** Flutter · Dart · Kotlin · Android · Telegram Bot API · SMS Integration · Background Processing
